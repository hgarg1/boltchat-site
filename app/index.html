Voice chat

A hands-free spoken conversation: Boltchat listens, answers out loud, and you can interrupt. Audio is never saved; it is sent to Groq to be transcribed, and the reply text is sent to be spoken.

VoiceWho reads the replies. Uses Groq's Orpheus text to speech (a preview model).
Answering modelVoice replies are short and spoken, so a fast model without a reasoning phase feels best. Web search and the code runner switch to GPT OSS when you turn them on in a call.
How you talkHands-free listens for you to pause. Push to talk records only while you hold Space or the orb.
Wait after you stop talkingHow long a pause means you are done. Shorter feels snappier but may cut you off mid-thought.
Interrupt by speakingTalk over the model to cut it off. Works best with headphones; on speakers the mic can hear the model and cut itself off. Tap the orb, Space or Esc always work.
HeadphonesWith headphones, interrupting reacts faster because the mic can't hear the model. Automatic guesses from the name of the sound device in use.
Show captionsThe words of the conversation on the call screen.
Say something while searchingA short phrase such as "Let me look that up" while a web search or code run is under way.
Use the system voice as a backupIf Groq's speech is rate limited or unavailable, read replies with a voice built into your browser or device instead of going quiet.
Longest spoken answerPast this length the model stops talking and says it can keep going; the full answer stays on screen.
End a quiet call afterCloses the microphone if nobody says anything for a while.
Start a call with the waveform button next to the mic, or press Ctrl+Shift+V. Speech costs a small amount on Groq's pay-as-you-go plan: roughly 4 cents an hour to transcribe and 2 cents per thousand spoken characters.

Code

The Code workspace lets the model read, search and change text files in folders you trust.

Apply AI changesReview shows every change as a diff first. Automatic writes changes straight away; each AI turn can still be undone.
Let the agent use the browserFor web projects: it opens pages in the built-in browser, clicks and types to test them, reads console errors, and asks a vision model to check how screenshots look. Sites outside your project need your OK.
Let the agent run commandsSo it can run your tests and builds and fix what fails. Commands run in the open folder with your user account; environment variables that look like secrets are removed.

Smart gate: GPT-OSS 20B checks each command first — tests, builds and read-only commands run; installs, network access, git history changes and deletions ask you; anything touching the system, other folders or secrets is blocked.

Trusted folders

Startup & background

How Boltchat starts with Windows, and what happens when you close it.

🚀 Open when I sign in to WindowsBoltchat starts with Windows, so it's ready the moment you need it.
🌙 Start quietlyWhen it opens at sign-in, it waits minimized (or in the notification area) instead of popping up.
When I close the windowReplies and coding-agent tasks run inside Boltchat, so quitting stops them.

✋ Ask before quitting mid-taskIf a reply or the coding agent is still working when you quit, choose to let it finish in the background, quit now, or stay.
🔔 Notify me about background workA Windows notification when a reply or agent task finishes, fails or needs your OK while Boltchat isn't the window you're using. Click it to jump right there.
