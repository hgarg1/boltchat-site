# Boltchat website

Marketing and legal pages for [Boltchat](https://boltchat.harshit-garg.com), a Windows chat app for the Groq API.
Served by GitHub Pages at boltchat.harshit-garg.com (see `CNAME`).

- `index.html` - landing page
- `privacy.html`, `terms.html`, `legal.html` - policies required for the Microsoft Store listing
