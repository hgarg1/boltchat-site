Install Boltchat and start chatting

A complete Windows setup guide

Boltchat is a free Windows desktop app that connects directly to models available through Groq. You provide your own Groq API key; Boltchat does not require a separate account.

What you need

Windows

64-bit Windows 10 version 1809 or later, or Windows 11.

Groq API key

A key from your Groq account. Groq may offer a free tier under its current limits.

Internet connection

The app runs locally, but the AI models run on Groq's servers.

Recommended

8 GB of memory for heavier Code workspace projects and a microphone for voice input.

Install from the Microsoft Store

  1. Open the official listing. Go to Boltchat in the Microsoft Store.
  2. Select Get or Install. Windows downloads the signed Store package and keeps it updated.
  3. Open Boltchat. Launch it from the Store, Start menu or Windows Search.

Use the Microsoft Store link on this website to avoid similarly named or unofficial downloads.

Create and connect a Groq API key

  1. Create a key. Sign in at console.groq.com/keys and create an API key.
  2. Paste it into Boltchat. The first-run screen asks for the key. You can change it later in Settings.
  3. Keep the key private. Treat it like a password. Boltchat protects a key entered in the app with Windows data protection tied to your Windows account.

Your requests travel directly from Boltchat to Groq. Read the privacy policy for the exact data flow and deletion controls.

Start your first chat

  1. Choose a model. Boltchat shows models that can handle the type of input or tool you want to use.
  2. Write a prompt. Ask a question, attach an image to a vision-capable model or use the microphone.
  3. Watch the answer stream. Boltchat shows the measured token speed and lets you stop, copy or regenerate the response.

Try the built-in tools

  • Type /web to search the web and receive source links.
  • Type /code to let the model run Python and show its code and output.
  • Enable optional memory in Settings, then review or delete every saved memory there.
  • Open the Code workspace to work with files in a folder you explicitly trust.

Troubleshooting

My API key is rejected

Copy the key again without spaces, confirm that it is active in your Groq account and check whether your Groq account has reached a current usage limit.

No models appear or requests fail

Confirm that Windows is online and that a firewall, VPN or managed network is not blocking HTTPS access to Groq. Then restart Boltchat and try again.

The microphone does not work

Open Windows Settings → Privacy & security → Microphone, allow microphone access and make sure Boltchat is permitted to use it.

The Code workspace cannot run a command

Some commands require your approval and clearly dangerous commands are blocked. Check Settings → Code for the selected command-approval mode. Tools such as Node.js or Git must also be installed on your PC before Boltchat can run them.

If the problem continues, send a bug report with your Boltchat version and the exact error text. Never include your API key.

Update or uninstall

The Microsoft Store handles Boltchat updates. To uninstall, open Windows Settings → Apps → Installed apps, find Boltchat and choose Uninstall. Removing the app can remove its locally stored application data; export anything you want to keep first.
