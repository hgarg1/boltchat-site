The short version: Boltchat has no accounts, no analytics and no servers of its own. Your chats — and, if you turn memory on, what Boltchat remembers about you — are stored only on your PC. When you send a message, it goes directly from your PC to Groq, the AI provider you connect with your own API key. The only other services the app contacts are a few public news websites, to download their lists of headlines; nothing about you is sent to them.

Who we are

Boltchat is developed by Harshit Garg ("we", "us"). This policy explains how the Boltchat app for Windows and this website handle information.

Information stored on your PC

Boltchat keeps the following on your computer only, in its app data folder (for the Store version, a private folder Windows manages for the app):

WhatWhy
Your chats, including any images you attachedSo you can reopen and search past conversations
Settings (model, theme, system prompt, tool, memory and suggestion switches)To remember your preferences
Code workspace: the list of folders you trusted, its AI conversations, AI changes waiting for review, and copies of files as they were before accepted AI changesSo you can pick up where you left off and undo AI changes (see Code workspace)
Memories: short facts about you, if you turn memory on (see Memory)So answers can be personalised across chats
The current start-screen suggestionsSo the new-chat screen shows ideas immediately instead of waiting for new ones
Your Groq API keyTo talk to Groq on your behalf. A key you paste into the app is encrypted with Windows' built-in data protection tied to your Windows account. If you choose to put a key in a .env file yourself, it is stored as plain text in that file.

We never receive a copy of any of this.

Information sent to Groq

Boltchat sends requests directly from your PC to Groq, Inc. using your API key. Depending on what you do, a request can include:

  • your messages, the earlier messages in that chat, and your system prompt;
  • if memory is on, your saved memories, which are included with every message; and, if automatic learning is on, your latest message and the reply, sent once more so a model can pick out facts worth remembering;
  • in the Code workspace, when you ask the AI panel or use an inline AI edit: the names and contents of text files the model reads from the folder you opened, your search queries it runs, the name of the file you have open and any code you selected; and, if you let the agent run commands, the commands it wants to run (sent to a small model on Groq for a safety check) and their output; and, if you let it use the built-in browser, the text of pages it checks and screenshots it asks a vision model on Groq to describe;
  • if fresh start-screen ideas are on, the day's news headlines and (when memory is on) your memories, so a model can write the suggestion buttons;
  • images you attach (vision models only);
  • audio you record with the microphone button, which Groq transcribes with Whisper. The microphone is used only while you are recording;
  • when web search is used, the model's search queries — Groq performs the search and reads the pages;
  • when the code runner is used, the Python code the model writes, which Groq runs in a sandbox.

Groq processes this data under its own terms and privacy policy, which you agreed to when creating your Groq account. See groq.com for details. We do not control and cannot see what Groq stores.

Memory

Memory is off by default. When you turn it on in Settings → Memory, Boltchat keeps short facts about you in a file on your PC (memory.json in the app data folder). A memory is saved when:

  • you add it yourself in Settings or with /remember;
  • you ask the model in a chat to remember something; or
  • "Learn automatically" is on, and a small model reading your latest message spots a lasting fact you shared about yourself. It is instructed to skip one-off requests, passwords and similar secrets, and sensitive topics such as health, finances, religion, politics and sexuality unless you ask it to remember them. Each learned memory is shown to you briefly and is labelled "learned" in the list.

You can see, add and delete every memory in Settings → Memory, ask the model to forget something, or use Forget everything. Turning memory off stops memories being sent or learned; delete them as well if you don't want them kept on your PC. Memories are sent to Groq as described above and are never sent to us.

News headlines

When Fresh start-screen ideas is on (Settings → Behavior, on by default), Boltchat downloads the public world-news RSS feeds of BBC News (UK), NPR, PBS NewsHour and the Christian Science Monitor (US), DW (Germany), France 24 (France) and CBC News (Canada) at most every few hours. On your PC, it merges reports of the same story and ranks stories by how many outlets cover them, then suggests a topical question on the new-chat screen. Each download is an ordinary web request: the outlet receives your IP address and basic technical details, as with any website, but no messages, memories or other information about you. Each outlet handles that request under its own privacy policy. Turn the setting off to stop these requests; the start screen then shows a fixed set of ideas.

Code workspace

The Code workspace lets you edit files in a folder on your PC and ask the AI to read and change them. It only works in folders you explicitly trust when opening them; Boltchat refuses any path outside such a folder, including through shortcuts and links.

  • File contents leave your PC only when the model reads a file to answer a request you made, and then only to Groq. Opening or editing files yourself sends nothing.
  • Binary files (images, archives, programs, office documents and similar) are never read by the AI or sent anywhere.
  • Folders like node_modules and .git, and anything matched by the folder's .gitignore, are skipped when the AI lists or searches files.
  • AI changes are shown for your review before anything is saved, unless you choose to apply them automatically in Settings → Code. Files the AI or you delete go to the Windows Recycle Bin.
  • To let you undo AI changes, Boltchat keeps copies of the affected files, as they were before, in its app data folder.
  • Commands. If you allow it in Settings → Code, the agent can run commands (such as your tests) on your PC, in the opened folder, with your Windows account. Before a command runs, it is checked: clearly dangerous commands are blocked, and with "Smart gate" a small AI model on Groq (GPT-OSS 20B) reviews the command text to decide whether it runs, asks you first, or is blocked. With "Ask every time" you approve each one. Environment variables that look like keys, tokens or passwords are removed before a command runs. Command output is sent to Groq so the agent can read it.

Remove a folder from Settings → Code to stop trusting it.

Terminal and browser

The Code workspace has a built-in terminal and a built-in browser.

  • Terminal. It runs a normal shell (PowerShell or Command Prompt) on your PC in the opened folder. What you type and its output stay on your PC; the AI doesn't see your terminal.
  • Browser. Pages you open load directly from their websites, as in any browser, in a separate browsing session with its own cookies and storage kept in Boltchat's app data folder. It has no access to your other browsers, blocks downloads and denies permission requests (camera, location and so on).
  • The agent in the browser. If you allow it (Settings → Code, on by default), the coding agent can open local pages and files from the opened folder, click and type in them to test your project, and read the page's console messages. It needs your OK before opening any other website. Page text it reads is sent to Groq; when it checks how a page looks, a screenshot of the browser area is sent to a vision model on Groq.

What we don't collect

Boltchat does not include analytics, advertising, crash-reporting or tracking code. It does not create an account, and it does not send your data to us or to anyone other than Groq. (The news headline downloads described above send no personal data. Websites you or the agent open in the built-in browser receive what any website receives from a visitor.) This website does not use cookies or analytics.

Reporting a response

If you use ⚑ Report on a reply, Boltchat opens your own email app with a pre-filled message containing the reason, the model name, your prompt and the reply. Nothing is sent unless you choose to send that email. If you do, we use it only to understand and address the problem, and we delete it on request.

Contact form on this website

If you send us a message with the contact form, the name, email address, topic, message and (if you give it) Boltchat version you enter are sent to Formspree, a form service that stores the submission and forwards it to us by email, under the Formspree Privacy Policy. We use it only to reply to you, and we delete it on request. The form sets no cookies.

Microsoft Store

If you install Boltchat from the Microsoft Store, Microsoft may collect information about installs, updates and crashes under the Microsoft Privacy Statement. We may see aggregated, non-identifying statistics that Microsoft provides to developers.

Your choices and deleting data

  • Delete any chat from the sidebar at any time.
  • Remove your saved key in Settings → API key.
  • Turn memory off, delete single memories or forget everything in Settings → Memory.
  • Stop trusting a folder in Settings → Code. Workspace conversations and undo copies are kept in the workspaces folder inside the app data folder; delete it to remove them.
  • Turn off the news download in Settings → Behavior → Fresh start-screen ideas.
  • Uninstalling removes the app; to remove everything, also delete the Boltchat folder in your app data (Settings → About → Open folder shows where it is).
  • To remove data held by Groq, use your Groq account or contact Groq.

Children

Boltchat is not directed to children under 13, and we do not knowingly collect information from them. Groq's own terms set a minimum age for using its API.

Changes to this policy

If we change how Boltchat handles data, we will update this page and the date at the top before the change takes effect.
