Frequently asked questions

What you need to know before installing Boltchat.

What is Boltchat?

Boltchat is a free app, for Windows and in open beta on Android, for chatting with models available through Groq. It adds web search, Python code execution, voice input, image understanding, optional memory and a coding workspace around those models.

Is there an Android version?

Yes, in open beta. It has the same chat engine, web search, Python, math, voice, optional memory and Projects as the Windows app, and replies keep streaming after you leave it. It has no Code workspace. Leave your email on the Android page and the tester link appears right there.

Is Boltchat made by or affiliated with Groq?

No. Boltchat is an independent app created and published by Harshit Garg. It connects directly to Groq using the API key you provide, but it is not affiliated with, endorsed by or sponsored by Groq, Inc.

Do I need a Groq API key?

Yes. Boltchat uses your own Groq API key, which you can create from your Groq account. A free Groq tier may be available, subject to Groq's current limits and terms.

Is Boltchat free?

The Boltchat app is free to install from the Microsoft Store. Your use of Groq is governed separately by Groq's limits, pricing and terms.

Which versions of Windows are supported?

Boltchat supports 64-bit Windows 10 version 1809 or later and Windows 11. An internet connection is required because the AI models run on Groq's servers.

Where are my chats and API key stored?

Chats and optional memories are stored on your PC. An API key entered in the app is protected with Windows data protection. Messages and selected content are sent directly to Groq when needed to answer your requests. Read the full privacy policy for exact details.
