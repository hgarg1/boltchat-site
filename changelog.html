Version 2.5.2

September 28, 2026 · Current Microsoft Store release

This release brings Boltchat's full chat and Code workspace experience to the Microsoft Store.

Highlights

  • Fast streaming chat with measured tokens per second.
  • Web search with visible queries, pages read and source links.
  • Python code execution with the generated code and exact output shown.
  • Voice input, image understanding, LaTeX math and chemistry rendering.
  • Optional memory with controls to review and delete saved facts.
  • A Monaco-based Code workspace with planning, reviewable diffs, undo and inline edits.
  • An integrated terminal and browser-based QA for web projects.
  • Persistent conversation branches when messages are edited or answers regenerated.
  • Background operation, completion notifications and optional start-with-Windows support.

See the installation guide or explore the Code workspace.

Getting updates

When installed from the Microsoft Store, Boltchat updates through the Store's normal application-update system. You can check for updates manually in Microsoft Store → Library → Get updates.

For support, send a message and include the version shown in Boltchat Settings → About. Never include your Groq API key.
